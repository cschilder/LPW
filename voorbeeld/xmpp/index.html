Hoe werkt XMPP?

XMPP (Jabber) is een open, gefedereerd chatprotocol: een stroom XML-stanza's tussen client en server. Er zijn drie soorten: <message>, <presence> en <iq> (vraag/antwoord). Deze demo praat er rechtstreeks vanuit je browser mee via XMPP-over-WebSocket (RFC 7395) — geen PHP-brug nodig.

1 · open<open to="domein"/> → server stuurt features
2 · SASLSCRAM-SHA-1/-256 (wachtwoord gaat nooit over de lijn) of PLAIN
3 · bindde server kent een resource toe → volledige JID
4 · presenceje bent online; contacten zien je status

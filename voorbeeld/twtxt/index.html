    Hoe werkt twtxt?

    twtxt (2016) is microbloggen zonder platform: je "account" is één tekstbestand op een webserver. Elke regel is een bericht:

    # nick = ada
# url  = https://jouwdomein.nl/voorbeeld/publiek/twtxt.txt
2026-10-04T09:12:00+02:00⇥Goedemorgen, twtxt!
2026-10-04T10:30:00+02:00⇥@<lin https://lin.nl/twtxt.txt> leuk idee!

    Volgen = de URL van iemands bestand toevoegen; je client haalt alle bestanden op en sorteert ze tot één tijdlijn. Vermeldingen hebben de vorm @<nick url>.

    Publiceren schrijft naar voorbeeld/publiek/twtxt.txt op deze server en vereist het beheerwachtwoord uit api/config.php. Feeds ophalen gaat via de PHP-brug api/twtxt.php (browsers mogen andermans bestanden meestal niet direct lezen vanwege CORS).

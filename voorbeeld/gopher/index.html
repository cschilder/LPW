    Publieke gopherholes

      Hoe werkt het?

      Gopher (1991) is een menu-gebaseerd protocol: de client stuurt een selector gevolgd door CRLF over TCP-poort 70 en de server antwoordt met een document of een gophermap (regels: type naam⇥selector⇥host⇥poort).

      Je browser kan geen ruwe TCP-verbindingen openen, dus deze app gebruikt de PHP-brug api/gopher.php op de server. In het Logboek zie je precies welke bytes de brug verstuurde en ontving.

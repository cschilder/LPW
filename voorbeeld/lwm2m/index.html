LwM2M modelleert een apparaat als objecten → instanties → resources, geadresseerd als /object/instantie/resource.

Zo stuurt het apparaat dit naar de server (SenML-JSON)







    
Hoe werkt LwM2M?

    

        
LwM2M (OMA SpecWorks, v1.2) is apparaatbeheer bovenop CoAP. Een apparaat registreert zich bij
        de server met een CoAP-POST naar /rd:

        
POST /rd?ep=lpw-demo&lt=300&lwm2m=1.1&b=U
Content-Format: 40 (link-format)
</>;rt="oma.lwm2m";ct=11543,</1/0>,</3/0>,</3303/0>

        

            
Register2.01 Created + Location-Path /rd/<id>

            
UpdatePOST /rd/<id> → 2.04 (vóór lifetime verloopt)

            
DeregisterDELETE /rd/<id> → 2.02

        

        
De standaardserver is de publieke Eclipse Leshan-sandbox; na registreren
        zie je je apparaat op leshan.eclipseprojects.io.
        Omdat de PHP-brug per verzoek draait (geen langlopend proces), kan de server het apparaat daarna
        niet zelf uitlezen; registratie, update en deregistratie zijn wél volledig echt.

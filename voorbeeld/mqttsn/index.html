Hoe werkt MQTT-SN?

    

        
MQTT-SN (v1.2) is MQTT voor sensoren op batterijen en radionetwerken (Zigbee, 6LoWPAN, LoRa): het draait
        over UDP en vervangt lange topicnamen door 2-byte topic-ID's. Een
        gateway vertaalt naar een gewone MQTT-broker.

        
sensor ──UDP/MQTT-SN──▶ gateway ──TCP/MQTT──▶ broker ──▶ dashboards, apps

        

            
REGISTERtopicnaam → topic-ID (één keer); daarna alleen het ID

            
QoS −1publiceren zónder CONNECT, met een vooraf afgesproken topic-ID — ideaal voor sensoren die maar af en toe wakker worden

            
Slapende clientsDISCONNECT met duur: de gateway buffert berichten tot de sensor wakker wordt

        

        
Eigen gateway draaien

        
Publieke MQTT-SN-gateways bestaan nauwelijks. Deze repo bevat een kleine gateway (Node.js) die je op je
        eigen pc of VPS kunt draaien (niet op gedeelde webhosting):

        
cd voorbeeld/mqttsn
npm install
BROKER=mqtt://broker.hivemq.com:1883 node gateway.js   # luistert op udp/1884

        
De PHP-brug api/mqttsn.php stuurt de binaire pakketten; het Logboek toont ze in hex.

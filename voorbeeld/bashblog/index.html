    Hoe werkt bashblog?
    
    
    
        
    bashblog
        is één Bash-script dat van Markdown-bestanden een complete statische blog maakt: een pagina per bericht,
        een index.html, all_posts.html, tagpagina's en een RSS-feed.
    
        
    Deze demo doet hetzelfde op de server in PHP en zet het resultaat in voorbeeld/publiek/blog/ —
        op Strato is je blog dus meteen live. Markdown wordt veilig omgezet (alle HTML in de bron wordt ge-escaped,
        javascript:-links worden geblokkeerd).
    
        
    publiek/blog/
├── index.html          laatste 10 berichten
├── 2026-10-04-titel.html
├── all_posts.html
├── tag_markdown.html
└── feed.rss

CoAP-servers beschrijven hun resources op /.well-known/core (CoRE Link Format, RFC 6690).

Hoe werkt CoAP?

CoAP is "HTTP voor microcontrollers": REST-methoden (GET/POST/PUT/DELETE) in compacte binaire berichten over UDP (poort 5683). De header is 4 bytes:

 Ver|T |TKL   Code      Message ID
 01  00 0100  010 00001 0x1234        → CON GET, token 4 bytes
 + token + opties (delta-gecodeerd) + 0xFF + payload
CON / NONbevestigd (met ACK + retransmissie) of niet
Piggybackedantwoord direct in de ACK
Separateeerst lege ACK, later een CON met het antwoord
Block1/Block2grote payloads in blokken van 16–1024 bytes (RFC 7959)

De PHP-brug api/coap.php doet dit allemaal; het Logboek toont elk datagram in hex.

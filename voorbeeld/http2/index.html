Je browser rapporteert via de Resource Timing API (nextHopProtocol) welk protocol hij voor elk bestand van déze pagina gebruikte:

h2 = HTTP/2 · h3 = HTTP/3 (QUIC) · http/1.1 = HTTP/1.1. Externe bestanden tonen alleen een waarde als de server dat toestaat (Timing-Allow-Origin).

Waarom HTTP/2?

HTTP/1.1 kan per TCP-verbinding maar één verzoek tegelijk afhandelen: het volgende moet wachten (head-of-line blocking). Browsers openen daarom tot 6 verbindingen per host — elk met een eigen TCP- en TLS-handshake.

HTTP/2 (RFC 9113) verpakt alles in binaire frames op genummerde streams, zodat tientallen verzoeken tegelijk over één verbinding gaan (multiplexing), met HPACK-headercompressie. De onderhandeling gebeurt in de TLS-handshake via ALPN (h2).

De PHP-brug api/http2.php haalt de URL's parallel op met curl en telt de gebruikte TCP-verbindingen via de lokale poortnummers.
